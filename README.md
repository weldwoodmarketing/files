# 🦍 Sasquatch Invaders 🪨🦝

A Space Invaders–style browser game where **Sasquatch defends the forest by throwing rocks at invading raccoons**. The raccoons march across the screen, drop closer each turn, and chuck acorns back at you — survive all 8 waves to win.

## 🎮 Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | `←` `→` or `A` `D` | Drag |
| Throw rock | `Space` | Tap |
| Start / restart | `Enter` or the button | Tap the button |

## 🌲 How to play

- You're **Sasquatch** at the bottom of the screen — hurl rocks upward at the raccoons.
- Clear every raccoon to advance to the next wave. There are **8 waves**.
- **Lose a life** (🌲) if an acorn hits you. **Game over** if any raccoon reaches the forest floor.
- Knocking out the back rows is worth more points. Your **high score** is saved in your browser.

## 🛠️ Tech

A single self-contained HTML file — no build step, no dependencies. Rendered with the Canvas API. Just open `sasquatch-invaders.html` in a browser, or play the hosted version above.
